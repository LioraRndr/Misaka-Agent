# MISAKA 中文图形界面

GUI 在本机浏览器中运行，复用 MISAKA 原有的会话、任务卡、研究流程、文档和配置。无需安装 Node.js，也不依赖外部 CDN。

日常对话是**原生会话**：消息在页面内直接完成，不经过终端。对话由一个无头会话进程驱动（`misaka.ui.gui.chat_runner`），它装配的和 `misaka chat` 完全相同——角色配置、内置扩展、技能、工具、会话持久化——只是没有终端界面。会话照常写成 JSONL，所以在 GUI 里开始的一段对话，随时可以用终端 `misaka chat --session <文件>` 继续，反之亦然。

侧栏以项目文件夹为入口：打开已有文件夹后，新对话在该目录运行；历史对话、任务和文件按项目展示。切换项目保留当前页面中的未发送草稿及原项目的后台会话。研究与任务通过结构化消息视图连接原会话，支持发送补充要求、暂停与恢复。旧版账号配置等向导位于设置中的“高级兼容工具”。

## 启动

Windows 在仓库根目录双击 `gui.cmd`。第一次会询问研究项目文件夹，之后记住这个选择。也可以带上路径：`gui.cmd --workspace 项目文件夹`。启动器会查找现有 MISAKA Python 环境，在后台运行网页服务并打开浏览器。再次双击会复用已启动的服务。

安装了本仓库版本后，Windows、macOS、Linux 均可在研究项目文件夹运行：

```sh
misaka gui
# 指定端口或手动打开浏览器
misaka gui --port 8765 --no-browser
```

也可以直接运行模块：

```sh
python -m misaka.ui.gui.server --workspace /path/to/my-research
```

Windows 已实际验证；macOS / Linux 共用标准库网页服务与原项目的跨平台终端后端，尚未进行本机验收。支持范围取决于原项目随包提供的终端库（主流 x86_64 / arm64）。这版交付为本地浏览器 GUI，不包含独立安装包。

## 功能

- **原生会话**：新建 Last Order / Sister 对话，输入即发送（Enter 发送、Shift+Enter 换行），回复逐字流式渲染 Markdown（标题、列表、表格、代码块、链接）。思考过程折叠展示；每次工具调用是一张可展开的卡片（工具名、参数、运行状态、结果）。回复过程中可以继续发消息插话（自动排队），也可以点顶栏“停止回复”中止并取消排队输入。
- **会话内操作**：顶栏可直接切换本次会话的模型与思考深度（不影响全局默认）、压缩上下文、重命名会话；输入 `/` 使用指令——`/new` `/model` `/thinking` `/compact` `/history` `/export` `/help` 由页面处理，其余（如 `/research` `/sister` `/board`）交给会话本身。可直接粘贴或拖入图片作为附件。
- **历史会话**：按身份列出已保存的会话，可"继续"（在页面内原生恢复）或"查看"（只读浏览）。正在终端窗格中运行的会话不会被重复打开，避免双写。
- **研究工作流**：问题、研究深度、节点上限、两种并行数、追加与修订轮次；研究记录及节点列表；恢复与停止研究。计划审批等其他参数在研究设置中调整，节点有会话记录时可点“打开对话”，在消息界面讨论计划；审批仍由原研究工具执行。
- **任务看板**：按状态展示当前项目任务；启动、查看、进入、继续与停止任务。
- **协作成员**：读取已有 Sister 的专长和模型，点击即在本页面开始对话。
- **文档与产物**：索引文档、原文检索、结构查看、引文核查、项目文件浏览和 UTF-8 文本预览。默认不生成需要模型调用的结构索引，勾选后启用。
- **技能与设置**：技能列表、待审阅项、项目扫描、组合、整理器，以及模型、联网、环境、项目、多模型协作等原生设置入口（这些向导在终端窗格中交互）。
- **原生命令入口**：其他能力可输入子命令与参数执行，完整原生交互显示在终端窗格中。不是系统 shell，不支持管道或 shell 命令。

关闭原生会话进程不会丢内容：记录已落盘，随时可从"历史会话"继续。只关闭网页不会停止后台研究或终端会话。

## 数据与访问

沿用原 MISAKA 数据目录、账号、模型与项目文件。切换项目只改变 GUI 当前视图，不终止其他项目。

服务仅监听 `127.0.0.1`；每次启动使用随机访问凭证，API 另校验 Host 与 Origin。请使用启动器打开的完整地址。页面刷新会保留当前标签页凭证；服务重启后重新运行启动器即可。启动日志位于仓库内的 `.gui-runtime`（已在 `.gitignore` 中），其中包含本次本机访问地址，不应提交或对外分享。原生会话进程的 stderr 记录在系统临时目录 `misaka-gui-chat-<id>.log`，仅用于排障。

## 验证

```sh
python -m unittest discover -s tests/gui -v
```

后端测试覆盖访问控制、参数校验、路径约束、会话复用、中文及多行输入、原后端转发，以及原生会话管理器的事件流、游标重放与进程清理（`tests/gui/fixtures/stub_chat_runner.py` 为协议桩，不装配真实模型）。真实模型生成与长时间研究执行需要现有有效账号，GUI 验收不自动花费模型额度。

在“设置与工具”点击“关闭网页服务”会停止网页对话并退出 GUI 服务；独立的 MISAKA 后端和研究进程继续运行。

## 项目工作方式

1. 点击侧栏“打开项目文件夹”，输入路径或逐级浏览文件夹。最近项目可直接切换；移除最近项目仅移除快捷入口。
2. 在当前项目新建对话，或点击侧栏历史记录继续。运行中的同一会话复用原进程，避免多个写入者。
3. 文件与材料页浏览当前项目目录；文档导入、检索和技能查询直接显示运行结果。
4. 研究启动后留在研究页查看进度；任务和研究对话使用消息界面，暂停后可点“恢复任务”。
5. 关闭浏览器保留后台会话；关闭网页服务会停止网页对话，独立研究进程仍继续。

最近项目保存在浏览器本地；启动器优先复用上次端口以保留这些记录。输入草稿仅在当前页面内按项目及会话保留，刷新前请自行保存。账号登录、部分全局配置和任意 CLI 命令仍使用单独的兼容工具页。
